# ShopCenter

A basic React shopping app starter inspired by Takealot and Amazon.

## What's included

- Vite + React setup
- Header with logo, search bar placeholder, and cart badge
- Product grid fetched from [Fake Store API](https://fakestoreapi.com/)
- Product cards with image, title, price, and rating

## What's next (step by step)

1. Make **Add to cart** actually work with React state
2. Build a **cart page** or sidebar
3. Add **search** and **category filters**
4. Add **product detail** page
5. Style polish and mobile improvements

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in your terminal (usually `http://localhost:5173`).
